## 📝 Description

Flappy Bird 2.0 is a recreation of the classic Flappy Bird game built with **Java Swing**. This project was developed as part of a team effort by **Group Apollo**.

## 👥 Team Members
- Lutho Sigodi
- Abona Ntsaluba
- **Tshephang Makgaloa**
- Okoyama Nomafaku Tantsi

**Mentor:** Sinenjabulo Gogwana

## 🎯 Features
- Classic Flappy Bird gameplay
- Keyboard (SPACEBAR) and touch controls
- Random pipe generation
- Score tracking
- Responsive design

## 🛠️ Technologies Used
- Java
- Swing (GUI framework)
- AWT (Graphics and events)
- Collections Framework
- Event-Driven Programming

## 🚀 How to Play
- **Desktop:** Press SPACEBAR to make the bird flap
- **Mobile:** Tap the screen to flap

## 📈 Future Improvements
- High score tracking with persistence
- Save/Load system
- Difficulty levels
- Sound effects
- Mobile support
